NMAP / ZENMAP - سؤال وجواب
==================================================

1) س1) استخدام Python لإيجاد:
الإجابة:
nmap <target1> <target2> <target3>

2) س3) Scan a Range of IP Addresses (فحص نطاق من عناوين IP)
الإجابة:
nmap 192.168.100.1-192.168.100.20

3) س4) Scan Multiple Networks/Subnets (فحص شبكات فرعية متعددة)
الإجابة:
nmap 192.168.1-100.*

4) س5) Scan an Entire Subnet using CIDR Notation (فحص شبكة فرعية كاملة)
الإجابة:
nmap 192.168.100.0/24

5) س6) Scan a List of Targets from a File (فحص قائمة أهداف من ملف)
الإجابة:
nmap -iL targets.txt

6) س7) Scan Random Targets (فحص أهداف عشوائية)
الإجابة:
nmap -iR 50

7) س8) Exclude Hosts from Scans (استبعاد أجهزة من الفحص)
الإجابة:
nmap 192.168.100.1 192.168.100.2 --exclude 192.168.100.5,192.168.100.10

8) س9) Exclude Targets Using a List File (استبعاد أهداف باستخدام ملف)
الإجابة:
nmap 192.168.100.1 192.168.100.2 --excludefile targets.txt

9) س10) Perform an Aggressive Scan (فحص عدواني)
الإجابة:
nmap -A 192.168.100.1

10) س11) Scan an IPv6 Target (فحص هدف IPv6)
الإجابة:
nmap -6 192.168.100.1

11) س12) Don't Ping (تخطي خطوة اكتشاف المضيف)
الإجابة:
nmap -Pn 192.168.100.1

12) س13) Ping Only Scan (فحص ping فقط بدون فحص المنافذ)
الإجابة:
nmap -sn 192.168.100.0/24

13) س14) TCP SYN Ping
الإجابة:
nmap -PS80,443 192.168.100.1

14) س15) TCP ACK Ping
الإجابة:
nmap -PA80,443 192.168.100.1

15) س16) UDP Ping
الإجابة:
nmap -PU 192.168.100.1

16) س17) ICMP Echo Ping
الإجابة:
nmap -PE 192.168.100.1

17) س18) ICMP Timestamp Ping
الإجابة:
nmap -PP 192.168.100.1

18) س19) ICMP Address Mask Ping
الإجابة:
nmap -PM 192.168.100.1

19) س20) IP Protocol Ping
الإجابة:
nmap -PO1,6,17 192.168.100.1

20) س21) ARP Ping
الإجابة:
nmap -PR 192.168.100.1

21) س22) Traceroute (تتبع المسار)
الإجابة:
nmap --traceroute 192.168.100.1

22) س23) Disable Reverse DNS Resolution (تعطيل حل DNS العكسي)
الإجابة:
nmap -n 192.168.100.1

23) س24) Manually Specify DNS Server(s) (تحديد خادم DNS يدوياً)
الإجابة:
nmap --dns-servers 8.8.8.8,1.1.1.1 192.168.100.1

24) س25) Create a Host List (Reverse DNS Lookup بدون إرسال حزم)
الإجابة:
nmap -sL 192.168.100.1

25) س26) TCP SYN Scan (فحص SYN - Stealth Scan)
الإجابة:
nmap -sS 192.168.100.1

26) س27) TCP Connect Scan
الإجابة:
nmap -sT 192.168.100.1

27) س28) UDP Scan
الإجابة:
nmap -sU 192.168.100.1

28) س29) Combination TCP/UDP Scan
الإجابة:
nmap -sS -sU 192.168.100.1

29) س30) TCP NULL Scan
الإجابة:
nmap -sN 192.168.100.1

30) س31) TCP FIN Scan
الإجابة:
nmap -sF 192.168.100.1

31) س32) Xmas Scan ("Christmas" Scan)
الإجابة:
nmap -sX 192.168.100.1

32) س33) Custom TCP Scan (فحص TCP مخصص بأعلام محددة)
الإجابة:
nmap --scanflags URGACKPSHRSTSYNFIN 192.168.100.1

33) س34) TCP ACK Scan (للكشف عن جدران الحماية)
الإجابة:
nmap -sA 192.168.100.1

34) س35) IP Protocol Scan
الإجابة:
nmap -sO 192.168.100.1

35) س36) Perform a Fast Scan (فحص سريع - أعلى 100 منفذ)
الإجابة:
nmap -F 192.168.100.1

36) س37) Scan Specific Ports (فحص منافذ محددة)
الإجابة:
nmap -p 20-25,80,443 192.168.100.1

37) س38) Scan Ports by Name (فحص منافذ بالاسم)
الإجابة:
nmap -p http,https,ssh 192.168.100.1

38) س39) Scan Ports by Protocol (فحص منافذ حسب البروتوكول)
الإجابة:
nmap -sU -sT -p U:53,161,T:22,80,443 192.168.100.1

39) س40) Scan All Ports (فحص جميع المنافذ 65,535)
الإجابة:
nmap -p- 192.168.100.1

40) س41) Scan Top Ports (فحص أعلى N منفذ شائع)
الإجابة:
nmap --top-ports 50 192.168.100.1

41) س42) Perform a Sequential Port Scan (فحص تسلسلي للمنافذ)
الإجابة:
nmap -r 192.168.100.1

42) س43) Only Display Open Ports (عرض المنافذ المفتوحة فقط)
الإجابة:
nmap --open 192.168.100.1

43) س44) Save Output to Normal Text File (حفظ النتائج في ملف نصي)
الإجابة:
nmap -oN /home/user/results.txt 192.168.100.1

44) س45) Save Output to XML File (حفظ النتائج في ملف XML)
الإجابة:
nmap -oX /home/user/results.txt 192.168.100.1
